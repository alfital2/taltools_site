Padoo for Windows

Use your iPhone as a trackpad and app deck for your Windows PC with Padoo.

Download for Windows

Release notes and all downloads

Requires Windows 10 or 11 (64-bit) and Padoo on iPhone. Download PadooWin-Setup.exe and run it to install the companion.

The current Windows installer is not code-signed, so Windows may show a SmartScreen warning. Read the publisher’s release notes before installing.

The customization screenshots and setup instructions on the main Padoo site currently show the Mac version.
